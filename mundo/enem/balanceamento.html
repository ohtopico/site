⚖️ Balança dos átomos

Ajuste os coeficientes com + e − até cada elemento ter o mesmo número de átomos dos dois lados (Lavoisier: nada se perde). A tabela mostra a conta enquanto você mexe.

Método das tentativas

1. Comece pelo elemento que aparece uma vez de cada lado (normalmente o metal ou o carbono). 2. Depois o hidrogênio. 3. Deixe o oxigênio por último. 4. Use os menores números inteiros possíveis.

Estrelas ficam guardadas só neste aparelho.
