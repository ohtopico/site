Cola rápida

Função afim y = a·x + b: b é o valor inicial (onde a reta corta o eixo y) e a é a taxa, quanto y muda quando x aumenta 1. Se a > 0 a reta sobe; se a < 0, desce.

Função quadrática y = a·x² + b·x + c: a < 0 dá parábola de boca para baixo (tem máximo); c é onde corta o eixo y; as raízes são onde ela toca o eixo x; o vértice fica em x = −b/2a.

Estrelas ficam guardadas só neste aparelho.
