O código da turma

Criar um código próprio e usá-lo para registrar uma informação.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Informação e códigos
Material
Cartolina, lápis de cor e a folha do estudante.

Habilidades da BNCC

  • EF01CO05: Representar informação usando diferentes codificações.

Passo a passo

  1. Votação (15 min): registre a fruta preferida de cada criança com um código (maçã = vermelho, banana = amarelo, uva = roxo). Cada criança pinta um quadradinho.
  2. Leitura do código (10 min): qual cor tem mais quadradinhos? Qual a fruta preferida da turma?
  3. Folha (15 min).
  4. Fechamento (10 min): a turma guardou informação usando um código, como o computador.

Texto para ler com a turma

Hoje a turma vai criar o próprio código. Cada fruta ganha uma cor. Cada criança pinta a cor da sua fruta preferida. No fim, olhando só as cores, a gente vai saber qual fruta a turma mais gosta.

Alunos com diferentes necessidades

Ofereça um código pronto para quem tem dificuldade de escolher e um código com quatro figuras para quem quer mais desafio.

Gabarito
  • Blocos 1 e 2: as cores escolhidas pela criança. A mensagem precisa usar a mesma cor para as duas flores.
  • Bloco 3: resposta pessoal.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
