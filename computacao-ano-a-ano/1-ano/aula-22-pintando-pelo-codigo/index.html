Pintando pelo código

Seguir um código para formar uma imagem, como o computador faz com os pontinhos da tela.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Informação e códigos
Material
A folha do estudante, lápis de cor e dispositivos com o jogo Código das Cores.

Habilidades da BNCC

  • EF01CO05: Representar informação usando diferentes codificações.

Passo a passo

  1. A tela de perto (10 min): mostre uma imagem muito ampliada no computador até aparecerem os quadradinhos. A imagem é feita de quadradinhos coloridos.
  2. Folha (20 min): pintar pelo código.
  3. Jogo (15 min): Código das Cores.
  4. Conversa (5 min): o que apareceu no desenho? Como o computador sabe a cor de cada quadradinho?

Texto para ler com a turma

As imagens da tela são feitas de quadradinhos bem pequenos. Cada quadradinho tem uma cor. O computador guarda um código que diz a cor de cada um. Hoje você vai fazer igual: seguir o código e descobrir o desenho.

Jogo da aula

Código das Cores: Jogo sem leitura para o 1º ano: pintar desenhos seguindo um código de formas e cores e traduzir mensagens escritas em cores.

Alunos com diferentes necessidades

Para estudantes cegos, faça a grade com texturas coladas (lixa, algodão, EVA) no lugar das formas e peça que a criança diga o desenho que sentiu.

Gabarito
  • Bloco 1: aparece uma casa: telhado vermelho em triângulo, parede amarela e céu azul.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
