Códigos secretos com cores

Representar informação usando um código de cores combinado.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Informação e códigos
Material
Cartões coloridos, uma legenda grande no quadro (por exemplo, sol = amarelo, peixe = azul, gato = vermelho) e a folha do estudante.

Habilidades da BNCC

  • EF01CO05: Representar informação usando diferentes codificações.

Passo a passo

  1. O código (10 min): mostre a legenda. Mostre uma fila de cartões coloridos e decifrem juntos a mensagem.
  2. Agentes secretos (20 min): em duplas, uma criança monta uma mensagem com cartões coloridos e a outra decifra usando a legenda.
  3. Folha (15 min).
  4. Conversa (5 min): por que o código só funciona se os dois conhecem a legenda?

Texto para ler com a turma

Um código é um combinado. Se a gente combinar que amarelo quer dizer sol, quem conhece o combinado entende a mensagem só olhando a cor. O computador também usa códigos para guardar as coisas: tudo vira código dentro dele.

Jogo da aula

Código das Cores: Jogo sem leitura para o 1º ano: pintar desenhos seguindo um código de formas e cores e traduzir mensagens escritas em cores.

Alunos com diferentes necessidades

Para estudantes com daltonismo, troque as cores por formas (círculo, quadrado, triângulo). O código continua funcionando.

Gabarito
  • Bloco 1: peixe, sol, gato.
  • Bloco 2: vermelho, vermelho, amarelo.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
