Algoritmo: a receita do computador

Relacionar uma sequência de passos à palavra algoritmo.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
2º: Passos e algoritmos
Material
Uma receita simples ilustrada (por exemplo, sanduíche), pão, recheio e a folha do estudante.

Habilidades da BNCC

  • EF01CO03: Reorganizar e criar sequências de passos em meios físicos ou digitais, relacionando essas sequências à palavra “algoritmos”.

Passo a passo

  1. Receita ao vivo (15 min): monte um sanduíche seguindo o que as crianças mandam, fazendo exatamente o que dizem (se disserem "põe o queijo", ponha em cima do pacote fechado). Rindo, a turma percebe que precisa ser precisa.
  2. A palavra nova (10 min): escreva ALGORITMO no quadro. Explique que é uma sequência de passos para resolver um problema.
  3. Folha (15 min).
  4. Fechamento (10 min): os jogos, os aplicativos e os robôs funcionam porque alguém escreveu algoritmos para eles.

Texto para ler com a turma

Hoje você vai aprender uma palavra de gente grande: algoritmo. Algoritmo é uma sequência de passos para resolver um problema. A receita de um bolo é um algoritmo. O caminho de casa até a escola é um algoritmo. O computador só funciona porque segue algoritmos.

Jogo da aula

Robô Ajudante: Jogo sem leitura para o 1º ano: organizar os passos de uma tarefa e criar o primeiro algoritmo com setas para o robô buscar as maçãs.

Alunos com diferentes necessidades

Para quem ainda não desenha com detalhe, ofereça figuras recortadas da rotina para colar nos quadrinhos.

Gabarito
  • Bloco 1: pão 1, colher (passar o recheio) 2, prato (servir) 3.
  • Bloco 2: a folha com passos escritos (uma receita).
  • Bloco 3: resposta livre em três passos, por exemplo vestir o pijama, escovar os dentes, deitar.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
