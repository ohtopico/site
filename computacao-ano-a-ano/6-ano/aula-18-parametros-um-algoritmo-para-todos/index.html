Parâmetros: um algoritmo para todos

Criar um algoritmo com parâmetro que resolve todos os casos de um problema.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Generalizar, transmitir e guardar
Material
Quadro e a folha do estudante.

Habilidades da BNCC

  • EF06CO06: Comparar casos particulares de um mesmo problema e criar um algoritmo que resolva todos, usando variáveis (parâmetros).

Passo a passo

  1. Retomada (10 min): a tabela das mesas.
  2. Algoritmo (15 min): "receba M; cadeiras = M × 4; mostre cadeiras". Testem com vários M.
  3. Folha (20 min).
  4. Fechamento (5 min): o parâmetro é a entrada que muda de um caso para outro.

Texto para ler com a turma

Em vez de escrever um programa para cada caso, escrevemos um só, com um parâmetro. O parâmetro é a parte que muda, e o algoritmo funciona para qualquer valor que entrar nele.

Jogo da aula

Um Algoritmo para Todos: Jogo para o 6º ano: comparar casos parecidos, achar o que muda (o parâmetro) e criar um só algoritmo que resolve todos.

Alunos com diferentes necessidades

Permita usar calculadora para os giros e tenha os polígonos recortados em papel.

Gabarito
  • Bloco 1: repita N vezes [ande 50, gire 360 ÷ N].
  • Bloco 2: 120, 90, 72, 60.
  • Bloco 3: receba P; fatias = P × 2; mostre fatias.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
