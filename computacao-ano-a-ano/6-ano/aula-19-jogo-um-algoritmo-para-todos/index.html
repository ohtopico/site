Jogo: Um Algoritmo para Todos

Praticar a generalização com parâmetros no jogo.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Generalizar, transmitir e guardar
Material
Dispositivos com o jogo Um Algoritmo para Todos e a folha do estudante.

Habilidades da BNCC

  • EF06CO06: Comparar casos particulares de um mesmo problema e criar um algoritmo que resolva todos, usando variáveis (parâmetros).

Passo a passo

  1. Jogo (25 min).
  2. Folha (15 min).
  3. Conversa (10 min): o que era o parâmetro em cada fase?

Texto para ler com a turma

No jogo, as escadas mudam de tamanho, mas o programa é o mesmo. Descubra o que muda e use isso como parâmetro.

Jogo da aula

Um Algoritmo para Todos: Jogo para o 6º ano: comparar casos parecidos, achar o que muda (o parâmetro) e criar um só algoritmo que resolve todos.

Alunos com diferentes necessidades

O jogo tem leitura e voz. Faça duplas de leitura quando necessário.

Gabarito
  • Bloco 1: depende do estudante (8 fases).
  • Bloco 2: repita N vezes [direita, baixo].
  • Bloco 3: resposta livre.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
