Ferramentas para criar

Conhecer ferramentas computacionais para criar textos, apresentações, vídeos e áudios e escolher a adequada.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
4º: Criar, cuidar e checar
Material
Computadores ou tablets com editor de texto, apresentação e gravador; dispositivos com o jogo Estúdio de Conteúdo.

Habilidades da BNCC

  • EF04CO06: Usar diferentes ferramentas computacionais para criação de conteúdo (textos, apresentações, vídeos etc.).

Passo a passo

  1. Tour (15 min): mostre cada ferramenta e um exemplo do que ela cria.
  2. Jogo (20 min): Estúdio de Conteúdo.
  3. Folha (15 min).

Texto para ler com a turma

Cada ferramenta é boa para um tipo de conteúdo: o editor de texto para escrever, a apresentação para mostrar ideias em telas, o editor de vídeo para juntar imagens e sons, o gravador para áudio.

Jogo da aula

Estúdio de Conteúdo: Jogo para o 4º ano: escolher a ferramenta computacional certa para criar textos, apresentações, vídeos e áudios, e organizar as etapas de uma produção.

Alunos com diferentes necessidades

Apresente recursos de acessibilidade das ferramentas: ditado por voz, leitor de tela, legendas automáticas.

Gabarito
  • Bloco 1: editor de texto; apresentação (slides); gravador de áudio; câmera e editor de vídeo.
  • Bloco 2: resposta pessoal.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
