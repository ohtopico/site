Computação · 4º ano · Aula 27 de 32 · 4º bimestre

Coletar dados com ética

Planejar uma pesquisa pedindo só os dados necessários, com permissão e explicando o uso.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
4º: Criar, cuidar e checar
Material
Dispositivos com o jogo Dados com Cuidado e a folha do estudante.

Habilidades da BNCC

  • EF04CO07: Demonstrar postura ética nas atividades de coleta, transferência, guarda e uso de dados.

Passo a passo

  1. Planejar uma pesquisa (15 min): sobre o esporte preferido. Que perguntas são necessárias? Precisa do nome? Do endereço?
  2. Jogo (20 min): Dados com Cuidado.
  3. Folha (15 min).

Texto para ler com a turma

Quando coletamos dados de pessoas, temos responsabilidade. Pedimos só o que é necessário, explicamos para que vamos usar e pedimos permissão. Dados de pessoas não são brinquedo.

Jogo da aula

Dados com Cuidado: Jogo para o 4º ano: decidir o que é ético na coleta, na guarda, no envio e no uso de dados, como numa pesquisa da turma.

Alunos com diferentes necessidades

Use exemplos concretos da escola. Para estudantes com TEA, deixe regras claras e escritas: só o necessário, pedir, explicar, guardar.

Gabarito
  • Bloco 1: necessárias: esporte preferido e se pratica. Endereço e telefone não.
  • Bloco 2: por exemplo "As respostas vão virar um gráfico da turma. Não vamos mostrar nomes."

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
