Computação · 4º ano · Aula 17 de 32 · 3º bimestre

Tudo vira número

Entender que, para guardar, manipular e transmitir dados, o computador os codifica em números (formato digital).

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Codificação da informação
Material
Um cartão com um código combinado (por exemplo, 1 = sim, 2 = não, 3 = talvez) e a folha do estudante.

Habilidades da BNCC

  • EF04CO04: Entender que para guardar, manipular e transmitir dados deve-se codificá-los de alguma forma que seja compreendida pela máquina (formato digital).

Passo a passo

  1. Código da turma (15 min): combine números para respostas. Faça perguntas e a turma responde só com números.
  2. Por quê? (10 min): o computador só entende números. Para guardar uma foto, um texto ou uma música, ele combina um código.
  3. Folha (20 min).
  4. Fechamento (5 min).

Texto para ler com a turma

O computador não guarda a foto como um papel, nem a música como um disco. Ele transforma tudo em números, usando um código combinado. Para mandar uma mensagem, os números viajam pelo cabo ou pelo ar e, do outro lado, são decodificados de novo.

Jogo da aula

Tudo Vira Número: Jogo para o 4º ano: descobrir que, para guardar e enviar dados, o computador codifica tudo em números, decodificando e codificando palavras com uma tabela de letras.

Alunos com diferentes necessidades

Para estudantes com deficiência visual, use o código com sons (1 palma = sol, 2 palmas = chuva).

Gabarito
  • Bloco 1: 1 1 2 3 1.
  • Bloco 2: nuvem, nuvem, sol, chuva, sol.
  • Bloco 3: porque ele só guarda e envia números; o código transforma a informação em números e de volta.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
