Computação · 4º ano · Aula 28 de 32 · 4º bimestre

Guardar, enviar e usar dados

Reconhecer atitudes éticas ao guardar, transferir e usar dados de outras pessoas.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
4º: Criar, cuidar e checar
Material
Cartões com situações e a folha do estudante.

Habilidades da BNCC

  • EF04CO07: Demonstrar postura ética nas atividades de coleta, transferência, guarda e uso de dados.

Passo a passo

  1. Situações (20 min): em grupos, a turma decide o que fazer em cada situação (achar a lista de telefones, receber a foto de um colega, emprestar o login).
  2. Folha (20 min).
  3. Combinado da turma (10 min).

Texto para ler com a turma

Os dados das pessoas precisam ser guardados com senha, enviados só para quem precisa e usados só para o que foi combinado. Se encontrar dados de alguém, entregue a um adulto.

Jogo da aula

Dados com Cuidado: Jogo para o 4º ano: decidir o que é ético na coleta, na guarda, no envio e no uso de dados, como numa pesquisa da turma.

Alunos com diferentes necessidades

Faça as situações como teatro curto para quem compreende melhor com ação.

Gabarito
  • Certo; errado (precisa de permissão); errado (uso diferente do combinado); certo.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
