O código das letras

Codificar e decodificar palavras com uma tabela de letras e números, como o computador faz (ideia do código ASCII).

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Codificação da informação
Material
Tabela A = 1 até Z = 26 e dispositivos com o jogo Tudo Vira Número.

Habilidades da BNCC

  • EF04CO04: Entender que para guardar, manipular e transmitir dados deve-se codificá-los de alguma forma que seja compreendida pela máquina (formato digital).
  • EF04CO05: Codificar diferentes informações para representação em computador (binária, ASCII, atributos de pixel, como RGB etc.).

Passo a passo

  1. Mensagem secreta (15 min): escreva no quadro uma mensagem em números para a turma decodificar.
  2. Jogo (20 min): Tudo Vira Número.
  3. Folha (15 min).

Texto para ler com a turma

Quando você digita a letra A, o computador guarda um número. Cada letra tem o seu número numa tabela que todos os computadores conhecem. Por isso uma mensagem escrita num celular aparece igualzinha no outro.

Jogo da aula

Tudo Vira Número: Jogo para o 4º ano: descobrir que, para guardar e enviar dados, o computador codifica tudo em números, decodificando e codificando palavras com uma tabela de letras.

Alunos com diferentes necessidades

Estudantes cegos podem usar a tabela em braille. Para quem tem dificuldade, use palavras de três letras.

Gabarito
  • Bloco 1: BOLA e CASA.
  • Bloco 2: depende do nome (ANA = 1 14 1).
  • Bloco 3: resposta livre; o colega deve conseguir decodificar.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
