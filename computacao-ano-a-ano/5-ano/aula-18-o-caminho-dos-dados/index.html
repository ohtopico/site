O caminho dos dados

Descrever o caminho dos dados entre os componentes: entrada, processamento, armazenamento e saída.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Por dentro do computador
Material
Dispositivos com o jogo Dentro do Computador e a folha do estudante.

Habilidades da BNCC

  • EF05CO05: Identificar os componentes principais de um computador (dispositivos de entrada/saída, processadores e armazenamento).

Passo a passo

  1. Computador humano (15 min): entrada recebe um número, processador soma 5, armazenamento anota no caderno, saída fala o resultado.
  2. Jogo (20 min).
  3. Folha (15 min).

Texto para ler com a turma

Quando você tira uma foto, a câmera (entrada) capta a imagem, o processador transforma em números, o armazenamento guarda e a tela (saída) mostra.

Jogo da aula

Dentro do Computador: Jogo para o 5º ano: identificar os componentes principais de um computador (entrada, saída, processador e armazenamento) e o caminho dos dados entre eles.

Alunos com diferentes necessidades

Cada papel do computador humano pode ser feito com gestos e cartões.

Gabarito
  • Bloco 1: microfone; processador; memória ou armazenamento do celular; alto-falante ou fone.
  • Bloco 2: depende da criança (6 fases).

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
