Dado e informação

Diferenciar dado (o registro solto) de informação (o que descobrimos a partir dos dados).

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Dados, formatos, entrada e saída
Material
Um saquinho com balas ou tampinhas coloridas e a folha do estudante.

Habilidades da BNCC

  • EF03CO04: Relacionar o conceito de informação com o de dado.

Passo a passo

  1. O saquinho (15 min): tire uma a uma as tampinhas e registre no quadro: azul, vermelha, azul... Esses são os dados.
  2. A pergunta (10 min): qual cor tem mais? Contando, descobrimos: tem mais azul. Isso é informação.
  3. Folha (15 min).
  4. Fechamento (10 min): o celular guarda dados (os passos que você deu) e mostra informação (você andou mais na terça).

Texto para ler com a turma

Dados são registros soltos: azul, vermelho, azul, azul. Sozinhos, eles não dizem muita coisa. Quando organizamos e contamos, descobrimos uma informação: "tem mais tampinhas azuis". Informação é o que os dados nos contam.

Jogo da aula

Contar Para Descobrir: Jogo sem leitura para o 3º ano: registrar dados (contar figuras de uma cena) e transformar os dados em informação, como descobrir o lanche preferido da turma.

Alunos com diferentes necessidades

Para estudantes com discalculia, use tampinhas para separar por grupos antes de contar. Estudantes cegos podem usar tampinhas de tamanhos diferentes.

Gabarito
  • Bloco 1: maçã 3, banana 2, pão 1.
  • Bloco 2: por exemplo "A maçã foi o lanche mais trazido" ou "Só uma pessoa trouxe pão".

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
