Jogo: Cada Coisa no Seu Formato

Material
Dispositivos com o jogo Cada Coisa no Seu Formato e a folha do estudante.

Habilidades da BNCC

  • EF03CO05: Compreender que dados são estruturados em formatos específicos dependendo da informação armazenada.

Passo a passo

  1. Retomada (5 min): foto, som, texto, tabela e vídeo.
  2. Jogo (25 min).
  3. Folha (15 min).
  4. Conversa (5 min): o vídeo junta quais formatos?

Texto para ler com a turma

No jogo, você escolhe o formato certo para guardar cada informação. Pense: é para ver, para ouvir ou para ler?

Jogo da aula

Cada Coisa no Seu Formato: Jogo sem leitura para o 3º ano: perceber que cada tipo de dado é guardado num formato (imagem, som, texto, tabela) e escolher o formato certo para cada informação.

Alunos com diferentes necessidades

Para quem precisa de apoio, use cartões com os formatos para manipular antes de responder no jogo.

Gabarito
  • Bloco 1: depende de cada criança (7 fases).
  • Bloco 2: imagens (foto) e som (nota musical).
  • Bloco 3: resposta livre e coerente (futebol: vídeo do gol; música: áudio).

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
