Jogo: Uma Parte de Cada Vez

Usar a decomposição no jogo: um programa para cada parte do caminho e separar tarefas em partes.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
1º: Verdadeiro, falso e partes
Material
Dispositivos com o jogo Uma Parte de Cada Vez e a folha do estudante.

Habilidades da BNCC

  • EF03CO03: Aplicar a estratégia de decomposição para resolver problemas complexos, dividindo esse problema em partes menores, resolvendo-as e combinando suas soluções.

Passo a passo

  1. Antes do jogo (10 min): mostre que cada parte resolvida fica guardada embaixo da malha.
  2. Jogo (25 min).
  3. Folha (10 min).
  4. Conversa (5 min): ficou mais fácil fazer o caminho em partes?

Texto para ler com a turma

No jogo, o robô tem que buscar várias coisas, uma de cada vez. Faça um programa pequeno para cada parte. No fim, todas as partes juntas resolvem o problema inteiro.

Jogo da aula

Uma Parte de Cada Vez: Jogo sem leitura para o 3º ano: dividir um problema grande em partes menores, resolver uma parte de cada vez e juntar as soluções.

Alunos com diferentes necessidades

Para quem precisa de apoio, jogue em trio, com uma criança responsável por cada parte do caminho.

Gabarito
  • Bloco 1: depende de cada criança (7 fases).
  • Bloco 2: respostas livres: guardar os brinquedos, arrumar a cama, pôr a roupa no cesto.
  • Bloco 3: semente 1, regador 2, flor 3.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
