Algoritmo em grupo

Criar em colaboração um algoritmo com repetição condicional para uma tarefa do dia a dia.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
2º: Repetir até
Material
Cartolina, canetas e a folha do estudante.

Habilidades da BNCC

  • EF03CO02: Criar e simular algoritmos representados em linguagem oral, escrita ou pictográfica, que incluam sequências e repetições simples com condição (iterações indefinidas), para resolver problemas de forma independente e em colaboração.

Passo a passo

  1. Escolher a tarefa (5 min): cada grupo escolhe uma tarefa: lavar a louça, encher um balde, arrumar os livros.
  2. Escrever (20 min): o grupo escreve o algoritmo com passos e pelo menos um "repita até".
  3. Testar (15 min): outro grupo executa o algoritmo em mímica, ao pé da letra.
  4. Folha (10 min).

Texto para ler com a turma

Hoje cada grupo vai escrever um algoritmo para uma tarefa de verdade. Ele precisa ter um "repita até". Por exemplo: "Coloque água no copo até ficar cheio". Depois, outro grupo vai testar fazendo exatamente o que está escrito.

Alunos com diferentes necessidades

Distribua papéis no grupo (quem escreve, quem desenha, quem testa). O algoritmo pode ser feito em desenho para quem ainda escreve com dificuldade.

Gabarito
  • Bloco 1: resposta livre. Exemplo: "1. Pegue o prato sujo. 2. Esfregue com a esponja até ficar limpo. 3. Enxágue até sair a espuma. 4. Repita até acabar a louça."
  • Blocos 2 e 3: depende do teste. Valorize as correções do grupo.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
