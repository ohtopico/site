Cada dado no seu formato

Reconhecer que os dados são guardados em formatos diferentes: imagem, som, texto, tabela, vídeo.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Dados, formatos, entrada e saída
Material
Um celular ou computador para mostrar uma foto, um áudio, um texto e uma planilha, e a folha do estudante.

Habilidades da BNCC

  • EF03CO05: Compreender que dados são estruturados em formatos específicos dependendo da informação armazenada.

Passo a passo

  1. Mostra e conta (15 min): mostre arquivos de cada formato. Como cada um guarda a informação? Com cores, com sons, com letras, com números.
  2. O mesmo bicho em formatos diferentes (10 min): uma foto do gato, o miado gravado, um texto sobre gatos. Tudo é informação sobre gatos.
  3. Folha (15 min).
  4. Fechamento (10 min): o computador precisa saber o formato para abrir o arquivo com o programa certo.

Texto para ler com a turma

O computador guarda as informações em formatos diferentes. A foto é uma imagem, feita de quadradinhos coloridos. A música é som. A história é texto. A lista de votos fica numa tabela. Cada formato combina com um tipo de informação.

Jogo da aula

Cada Coisa no Seu Formato: Jogo sem leitura para o 3º ano: perceber que cada tipo de dado é guardado num formato (imagem, som, texto, tabela) e escolher o formato certo para cada informação.

Alunos com diferentes necessidades

Estudantes cegos podem explorar o formato de áudio gravando a própria voz; estudantes surdos, o formato de vídeo com sinais.

Gabarito
  • Bloco 1: pássaro (o canto) com som; flor (a aparência) com foto; bolo (a receita) com texto; gráfico (os votos) com tabela.
  • Bloco 2: som (áudio); imagem (foto ou desenho digital); texto ou tabela.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
