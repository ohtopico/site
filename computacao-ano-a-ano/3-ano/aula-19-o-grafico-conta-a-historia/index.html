O gráfico conta a história

Transformar os dados de uma tabela num gráfico de colunas e tirar informações dele.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Dados, formatos, entrada e saída
Material
Papel quadriculado, lápis de cor, dispositivos com o jogo Contar Para Descobrir e a folha do estudante.

Habilidades da BNCC

  • EF03CO04: Relacionar o conceito de informação com o de dado.

Passo a passo

  1. Do quadro ao gráfico (15 min): use os dados da aula passada e pinte uma coluna de quadradinhos para cada bicho.
  2. Jogo (20 min): Contar Para Descobrir.
  3. Folha (15 min).

Texto para ler com a turma

O gráfico é um desenho dos dados. Cada coluna mostra uma resposta, e quanto mais alta a coluna, mais votos. Olhando o gráfico, a gente vê a informação num instante.

Jogo da aula

Contar Para Descobrir: Jogo sem leitura para o 3º ano: registrar dados (contar figuras de uma cena) e transformar os dados em informação, como descobrir o lanche preferido da turma.

Alunos com diferentes necessidades

Para estudantes cegos, monte o gráfico com pecinhas de encaixar empilhadas, que dá para comparar pelo tato.

Gabarito
  • Bloco 1: coluna do sol com 4 quadradinhos, da chuva com 1, da nuvem com 2 (pintados de baixo para cima).
  • Bloco 2: fez mais sol; fez menos chuva.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
