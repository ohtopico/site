Computação · 2º ano · Aula 18 de 32 · 3º bimestre

O robô que anda e gira

Programar uma máquina com outro conjunto de instruções: andar para a frente, girar para a direita e girar para a esquerda.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Máquinas, hardware e software
Material
Cartões com ⇧ (frente), ↻ (girar para a direita) e ↺ (girar para a esquerda), malha no chão e a folha do estudante.

Habilidades da BNCC

  • EF02CO03: Identificar que máquinas diferentes executam conjuntos próprios de instruções e que podem ser usadas para definir algoritmos.

Passo a passo

  1. Robô de frente (20 min): uma criança é o robô e só entende três ordens: anda para a frente, gira para a direita e gira para a esquerda. A turma leva o robô até um objeto.
  2. Comparação (10 min): com as setas, falávamos "vai para a direita". Agora o robô precisa primeiro girar e depois andar.
  3. Folha (15 min).
  4. Fechamento (5 min): muitos robôs de verdade, como o aspirador robô, funcionam assim.

Texto para ler com a turma

Este robô é diferente. Ele não entende "vai para a direita". Ele só sabe andar para a frente e girar. Para ir para a direita, ele gira e depois anda. É outra máquina, então é outro jeito de dar ordens.

Jogo da aula

Cada Máquina do Seu Jeito: Jogo sem leitura para o 2º ano: programar duas máquinas que entendem instruções diferentes (setas ou andar e girar) e ligar cada máquina ao que ela faz.

Alunos com diferentes necessidades

Use um boné com aba para mostrar para onde o robô humano está olhando. Para estudantes com lateralidade em construção, cole uma fita vermelha na mão direita.

Gabarito
  • Bloco 1: anda duas casas para a direita, gira para a direita (agora olha para baixo) e anda duas: última linha, terceira casa.
  • Bloco 2: ⇧ ⇧ ↻ ⇧ (anda duas, gira para a direita e desce uma). Outra resposta: ↻ ⇧ ↺ ⇧ ⇧.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
