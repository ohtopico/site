Software: os programas

Reconhecer o software: os programas e arquivos que dão as instruções para o hardware.

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Máquinas, hardware e software
Material
Um computador, tablet ou celular ligado ao projetor e a folha do estudante.

Habilidades da BNCC

  • EF02CO04: Diferenciar componentes físicos (hardware) e programas que fornecem as instruções (software) para o hardware.

Passo a passo

  1. O que tem dentro (15 min): abra no aparelho um jogo, um desenho, uma música e um vídeo. Dá para pegar o jogo com a mão? Não: ele é software.
  2. O aparelho desligado (5 min): desligue a tela. O hardware continua ali, mas sem programa ele não faz nada.
  3. Folha (20 min).
  4. Fechamento (10 min): o hardware é o corpo e o software são as ideias e as instruções.

Texto para ler com a turma

O jogo, a música, as fotos e o aplicativo de desenhar ficam dentro do aparelho, mas a gente não consegue pegar com a mão. Eles são software: programas e arquivos. O software diz para o hardware o que fazer. Sem software, o computador não sabe fazer nada.

Jogo da aula

Toca ou Não Toca?: Jogo sem leitura para o 2º ano: separar o que é hardware (dá para tocar) do que é software (programas e arquivos) e ligar cada aparelho ao programa que ele usa.

Alunos com diferentes necessidades

Para estudantes com dificuldade de abstração, use a comparação do rádio: o aparelho é hardware e a música que sai dele é software.

Gabarito
  • Bloco 1: jogo, foto e música.
  • Bloco 2: mão (hardware): mouse e fone. Aplicativo (software): jogo e vídeo.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
