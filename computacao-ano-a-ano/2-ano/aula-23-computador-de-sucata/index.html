Computador de sucata

Montar um modelo de computador com sucata, nomeando as peças (hardware) e inventando os programas (software).

Caderno do ano (PDF)
Tempo
50 minutos
Bimestre
3º: Máquinas, hardware e software
Material
Caixas, tampinhas, rolos, cola, tesoura sem ponta, canetinhas e a folha do estudante.

Habilidades da BNCC

  • EF02CO04: Diferenciar componentes físicos (hardware) e programas que fornecem as instruções (software) para o hardware.
  • EF02CO03: Identificar que máquinas diferentes executam conjuntos próprios de instruções e que podem ser usadas para definir algoritmos.

Passo a passo

  1. Planejar (10 min): que peças o nosso computador vai ter? Tela, teclado, mouse, caixa de som.
  2. Montar (25 min): em grupos, a turma constrói o computador com sucata.
  3. Programas (10 min): cada grupo desenha na tela os aplicativos que o computador terá.
  4. Folha (5 min).

Texto para ler com a turma

Hoje vamos construir um computador de sucata. As caixas e as tampinhas vão ser o hardware. E os desenhos na tela vão ser os programas, o software. Lembre: o computador só funciona quando tem as duas coisas.

Alunos com diferentes necessidades

Divida as tarefas no grupo conforme as habilidades de cada um: recortar, colar, desenhar, explicar. Estudantes cegos podem montar e nomear as peças pelo tato.

Gabarito
  • Bloco 1: o desenho deve ter peças como tela, teclado e mouse circuladas.
  • Bloco 2: resposta livre: jogos, desenho, música, vídeo.

Folha para imprimir

A folha é A4 com fundo branco, para economizar tinta. A segunda folha traz as orientações e o gabarito para o professor.
