Como usar

Três peças representam os termos: o quadrado grande é x², a barra é x e o quadradinho é 1. As peças vermelhas são negativas. Uma peça positiva e uma negativa do mesmo tipo formam um par zero e se anulam.

Polinômios: escolha os coeficientes de P e Q e junte as peças para somar ou subtrair. Fatoração: arraste as peças para formar um retângulo sem buracos. Toque numa barra para girá-la. Os lados do retângulo são os fatores.

Arraste o fundo da cena para girar; use a roda do mouse ou dois dedos para aproximar. Pelo teclado: Tab até a cena, setas giram e as teclas + e − aproximam. Todos os comandos também estão nos botões.

Para o professor

Metodologia sugerida: rotação por estações com material manipulável. Estação 1: blocos de papel (veja a atividade desplugada). Estação 2: este recurso. Estação 3: registro simbólico no caderno, conferindo com o colega.

  1. Termos semelhantes: por que 2x + 3 não vira 5x? As peças têm formas diferentes e não se juntam numa só.
  2. Par zero: some (x² − 2x + 1) com (−x² + 3x). As peças vermelhas anulam as positivas do mesmo tipo.
  3. Subtração: P − Q é P mais o oposto de Q. Veja as peças de Q trocarem de cor antes de juntar.
  4. Fatoração: para x² + 5x + 6, as barras x precisam ser divididas entre os dois lados. Qual divisão fecha o retângulo? Os lados lidos ficam (x + 2)(x + 3).
  5. Ligação com o 9º ano: a fatoração permite resolver x² + 5x + 6 = 0 sem fórmula (EF09MA09).

Habilidades: EF08MA06 e EF09MA09. A BNCC não tem uma habilidade só para operações com polinômios; elas aparecem como base do cálculo algébrico do 8º e do 9º ano.
