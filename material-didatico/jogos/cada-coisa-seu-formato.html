Cada Coisa no Seu Formato

Jogo sem leitura para o 3º ano: perceber que cada tipo de dado é guardado num formato (imagem, som, texto, tabela) e escolher o formato certo para cada informação.

EF03CO05
Como jogar (para o adulto)

As caixas mostram os formatos: a foto (imagem), a nota musical (som), a folha (texto) e a tabela (números organizados). A criança escolhe em qual formato cada informação fica guardada.

Converse: a foto do pássaro e o canto do pássaro são informações sobre o mesmo bicho, mas ficam em formatos diferentes.

O jogo não pede leitura: as instruções são as figuras, os sons e a voz do botão com o alto-falante. A lâmpada mostra uma dica. Cada fase completa vira uma estrela.

Este jogo faz parte do ano letivo de Computação do 3º ano, com texto, atividade para imprimir e gabarito.

Para o professor

Cada Coisa no Seu Formato é um jogo gratuito de Computação para o 3º ano, pensado para cerca de 10–15 min de aula. Funciona no navegador do computador, do tablet ou do celular, sem cadastro e sem instalar nada. Jogo sem leitura para o 3º ano: perceber que cada tipo de dado é guardado num formato (imagem, som, texto, tabela) e escolher o formato certo para cada informação.

Habilidades da BNCC trabalhadas:

  • EF03CO05: Compreender que dados são estruturados em formatos específicos dependendo da informação armazenada.
