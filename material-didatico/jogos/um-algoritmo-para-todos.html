📖 Antes de começar, aprenda: Um algoritmo para muitos casos

Como jogar (para o adulto)

Generalizar é olhar vários casos de um problema, ver o que fica igual e o que muda, e escrever uma solução só que serve para todos. O que muda vira um parâmetro, uma entrada do algoritmo.

Nas fases do robô, as escadas têm tamanhos diferentes, mas o desenho é o mesmo: só muda o número de repetições.

O botão com o alto-falante lê a instrução em voz alta e a lâmpada mostra uma dica. Cada fase completa vira uma estrela.

Este jogo faz parte do ano letivo de Computação do 6º ano, com texto, atividade para imprimir e gabarito.

Para o professor

Um Algoritmo para Todos é um jogo gratuito de Computação para o 6º ano, pensado para cerca de 15–20 min de aula. Funciona no navegador do computador, do tablet ou do celular, sem cadastro e sem instalar nada. Jogo para o 6º ano: comparar casos parecidos, achar o que muda (o parâmetro) e criar um só algoritmo que resolve todos.

Habilidades da BNCC trabalhadas:

  • EF06CO06: Comparar casos particulares de um mesmo problema e criar um algoritmo que resolva todos, usando variáveis (parâmetros).
