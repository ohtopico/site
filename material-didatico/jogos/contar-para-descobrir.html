Contar Para Descobrir

Jogo sem leitura para o 3º ano: registrar dados (contar figuras de uma cena) e transformar os dados em informação, como descobrir o lanche preferido da turma.

EF03CO04
Como jogar (para o adulto)

Em cada fase há uma cena com figuras misturadas. A criança toca no botão de cada figura para marcar uma barrinha a cada uma que contar. Quando a contagem está certa, o jogo pergunta qual tem mais ou qual tem menos.

Converse: as figuras soltas são os dados. A resposta "a turma prefere bolo" é a informação que os dados nos dão.

O jogo não pede leitura: as instruções são as figuras, os sons e a voz do botão com o alto-falante. A lâmpada mostra uma dica. Cada fase completa vira uma estrela.

Este jogo faz parte do ano letivo de Computação do 3º ano, com texto, atividade para imprimir e gabarito.

Para o professor

Contar Para Descobrir é um jogo gratuito de Computação para o 3º ano, pensado para cerca de 15 min de aula. Funciona no navegador do computador, do tablet ou do celular, sem cadastro e sem instalar nada.
