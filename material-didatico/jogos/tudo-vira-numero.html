Tudo Vira Número

Jogo para o 4º ano: descobrir que, para guardar e enviar dados, o computador codifica tudo em números, decodificando e codificando palavras com uma tabela de letras.

EF04CO04
Como jogar (para o adulto)

A tabela de código troca cada letra por um número: A é 1, B é 2, C é 3 e assim por diante. É uma versão simples do que o computador faz com cada letra que digitamos.

Converse depois: a foto vira números (as cores de cada quadradinho), a música vira números (a altura do som a cada instante).

O botão com o alto-falante lê a instrução em voz alta e a lâmpada mostra uma dica. Cada fase completa vira uma estrela.

Este jogo faz parte do ano letivo de Computação do 4º ano, com texto, atividade para imprimir e gabarito.

Para o professor

Tudo Vira Número é um jogo gratuito de Computação para o 4º ano, pensado para cerca de 15 min de aula. Funciona no navegador do computador, do tablet ou do celular, sem cadastro e sem instalar nada. Jogo para o 4º ano: descobrir que, para guardar e enviar dados, o computador codifica tudo em números, decodificando e codificando palavras com uma tabela de letras.

Habilidades da BNCC trabalhadas:

  • EF04CO04: Entender que para guardar, manipular e transmitir dados deve-se codificá-los de alguma forma que seja compreendida pela máquina (formato digital).
