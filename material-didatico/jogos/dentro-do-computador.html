Dentro do Computador

Jogo para o 5º ano: identificar os componentes principais de um computador (entrada, saída, processador e armazenamento) e o caminho dos dados entre eles.

EF05CO05
Como jogar (para o adulto)

As quatro caixas são: entrada (o que leva dados para dentro), processador (o chip que faz as contas), armazenamento (onde os dados ficam guardados) e saída (o que mostra o resultado).

Se houver um computador velho na escola, abra com a turma (com cuidado e desligado da tomada) e procure as peças.

O botão com o alto-falante lê a instrução em voz alta e a lâmpada mostra uma dica. Cada fase completa vira uma estrela.

Este jogo faz parte do ano letivo de Computação do 5º ano, com texto, atividade para imprimir e gabarito.

Para o professor

Dentro do Computador é um jogo gratuito de Computação para o 5º ano, pensado para cerca de 10–15 min de aula. Funciona no navegador do computador, do tablet ou do celular, sem cadastro e sem instalar nada.
