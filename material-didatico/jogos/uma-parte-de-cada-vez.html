Uma Parte de Cada Vez

Jogo sem leitura para o 3º ano: dividir um problema grande em partes menores, resolver uma parte de cada vez e juntar as soluções.

EF03CO03
Como jogar (para o adulto)

Nas fases de caminho, o robô precisa buscar as coisas numa ordem. A criança faz um programa pequeno para cada parte; cada parte resolvida fica guardada embaixo, e o programa inteiro é a soma delas.

Nas fases de separar, a festa, a mochila e a horta viram partes menores: comida, enfeite e música, por exemplo.

O jogo não pede leitura: as instruções são as figuras, os sons e a voz do botão com o alto-falante. A lâmpada mostra uma dica. Cada fase completa vira uma estrela.

Este jogo faz parte do ano letivo de Computação do 3º ano, com texto, atividade para imprimir e gabarito.

Para o professor

Uma Parte de Cada Vez é um jogo gratuito de Computação para o 3º ano, pensado para cerca de 15 min de aula. Funciona no navegador do computador, do tablet ou do celular, sem cadastro e sem instalar nada. Jogo sem leitura para o 3º ano: dividir um problema grande em partes menores, resolver uma parte de cada vez e juntar as soluções.

  • EF03CO03: Aplicar a estratégia de decomposição para resolver problemas complexos, dividindo esse problema em partes menores, resolvendo-as e combinando suas soluções.
