Código das Cores

Jogo sem leitura para o 1º ano: pintar desenhos seguindo um código de formas e cores e traduzir mensagens escritas em cores.

EF01CO05
Como jogar (para o adulto)

No alto aparece o código: cada forma vale uma cor. A criança escolhe a cor embaixo e toca nos quadradinhos com aquela forma até aparecer o desenho.

Nas fases de mensagem secreta, as figuras viraram cores. Usando o código, ela troca cada cor pela figura certa.

O jogo não pede leitura: as instruções são as figuras, os sons e a voz do botão com o alto-falante. A lâmpada mostra uma dica. Cada fase completa vira uma estrela.

Este jogo faz parte do ano letivo de Computação do 1º ano, com texto, atividade para imprimir e gabarito.

Para o professor

Código das Cores é um jogo gratuito de Computação para o 1º ano, pensado para cerca de 15 min de aula. Funciona no navegador do computador, do tablet ou do celular, sem cadastro e sem instalar nada.
