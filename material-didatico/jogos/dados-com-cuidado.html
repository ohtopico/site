Dados com Cuidado

Jogo para o 4º ano: decidir o que é ético na coleta, na guarda, no envio e no uso de dados, como numa pesquisa da turma.

EF04CO07
Como jogar (para o adulto)

Cada fase traz uma situação com dados de pessoas. A criança decide se a atitude está certa ou errada, ou escolhe a melhor atitude.

Princípios para combinar com a turma: pedir só os dados necessários, pedir permissão, contar para que vão ser usados, guardar com cuidado e não espalhar.

O botão com o alto-falante lê a instrução em voz alta e a lâmpada mostra uma dica. Cada fase completa vira uma estrela.

Este jogo faz parte do ano letivo de Computação do 4º ano, com texto, atividade para imprimir e gabarito.

Para o professor

Dados com Cuidado é um jogo gratuito de Computação para o 4º ano, pensado para cerca de 10–15 min de aula. Funciona no navegador do computador, do tablet ou do celular, sem cadastro e sem instalar nada.
