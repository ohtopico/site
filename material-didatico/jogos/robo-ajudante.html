Robô Ajudante

Jogo sem leitura para o 1º ano: organizar os passos de uma tarefa e criar o primeiro algoritmo com setas para o robô buscar as maçãs.

EF01CO03
Como jogar (para o adulto)

Primeiro a criança arruma os passos de tarefas conhecidas, como lavar as mãos. Depois monta uma fila de setas (o algoritmo) e aperta o botão verde para o robô seguir.

Se o robô bater numa árvore ou não pegar todas as maçãs, ele volta ao começo e a fila de setas continua lá para ser corrigida. Tocar numa seta da fila apaga só ela.

O jogo não pede leitura: as instruções são as figuras, os sons e a voz do botão com o alto-falante. A lâmpada mostra uma dica. Cada fase completa vira uma estrela.

Este jogo faz parte do ano letivo de Computação do 1º ano, com texto, atividade para imprimir e gabarito.

Para o professor

Robô Ajudante é um jogo gratuito de Computação para o 1º ano, pensado para cerca de 15 min de aula. Funciona no navegador do computador, do tablet ou do celular, sem cadastro e sem instalar nada.
