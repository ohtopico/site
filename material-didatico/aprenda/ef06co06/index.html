Um algoritmo para muitos casos

  1. 1. Aprenda
  2. 2. Confira
  3. 3. Pratique

A ideia principalQuando vários problemas são parecidos, dá para criar um só algoritmo que resolve todos, trocando apenas os valores que mudam.

Desenhar um quadrado, um triângulo e um hexágono parece ser três problemas. Mas olhe o padrão: em todos você anda e vira, repetindo. O que muda é quantos lados a figura tem.

Esse valor que muda vira um parâmetro (uma variável). Assim você escreve o algoritmo uma vez só e usa para qualquer figura. Isso é generalização.

No dia a dia: Uma receita de bolo “para N pessoas”: você muda N e as quantidades se ajustam, sem precisar de uma receita nova.

Palavras para lembrar

Generalização
resolver vários casos parecidos com uma só solução.
Parâmetro
o valor que muda de um caso para outro.

Confira se entendeu

No algoritmo “desenhe_figura(lados)”, o que é “lados”?

“lados” é o valor que muda de uma figura para outra: o parâmetro.
