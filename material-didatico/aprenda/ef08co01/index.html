Recursão: resolver usando o próprio problema

  1. 1. Aprenda
  2. 2. Confira
  3. 3. Pratique

A ideia principalRecursão é resolver um problema usando uma versão menor dele mesmo, até chegar num caso tão pequeno que a resposta é óbvia.

Para contar quantas pessoas há numa fila sem sair do lugar, você pergunta para quem está na sua frente: “quantas pessoas há na sua frente?”. Cada um faz a mesma pergunta para o da frente, até o primeiro responder “nenhuma”. Aí cada um soma 1 e passa a resposta de volta.

Toda recursão tem duas partes: o caso base (a resposta direta, que para a repetição) e o passo recursivo (chamar a mesma solução para um problema menor). Sem caso base, o programa nunca para.

No dia a dia: Bonecas russas: para abrir todas, você abre uma e repete com a de dentro, até achar a menor, que não abre.

Palavras para lembrar

Recursão
uma função que chama a si mesma.
Caso base
a situação simples em que a recursão para.

Confira se entendeu

O que acontece com uma recursão sem caso base?

Sem caso base, a função continua se chamando para sempre, até o programa travar.
