Tabelas, bancos de dados e gráficos

  1. 1. Aprenda
  2. 2. Confira
  3. 3. Pratique

A ideia principalOs mesmos dados podem ser guardados em tabelas, consultados em bancos de dados e mostrados em gráficos. Cada forma serve para um objetivo.

Uma tabela organiza dados em linhas (registros) e colunas (campos). Um banco de dados guarda muitas tabelas e permite consultas: “mostre os estudantes do 1º ano com nota maior que 8”.

Um gráfico mostra padrões de uma vez: barras para comparar, linhas para ver mudanças no tempo, pizza para partes de um todo. Escolher o gráfico errado (ou cortar o eixo) pode enganar quem lê.

No dia a dia: Numa feira de ciências, a turma guardou as medições numa planilha, filtrou os dias de chuva e fez um gráfico de linha da temperatura.

Palavras para lembrar

Banco de dados
sistema que guarda e organiza muitos dados.
Consulta
pergunta feita ao banco de dados.
Filtro
mostrar só os registros que atendem a uma condição.

Confira se entendeu

Para mostrar como a temperatura mudou ao longo do mês, qual gráfico é mais adequado?

Gráficos de linha mostram mudanças ao longo do tempo.
