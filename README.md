## Computação (BNCC, 6º ao 9º ano)

Uma aula expositiva de 30 minutos para cada uma das 42 habilidades de Computação dos anos finais do Ensino Fundamental, com slides prontos e roteiro para o professor. Os eixos são pensamento computacional, mundo digital e cultura digital.
