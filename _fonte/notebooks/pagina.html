Notebooks de aula com dados da Wikipédia

Cinco aulas interativas para o Google Colab. Os alunos baixam dados abertos de verdade, fazem gráficos, testam previsões e constroem um pequeno modelo de linguagem, tudo no navegador e sem instalar nada.

Escolha a aula

Como usar

Primeira vez no Colab

  1. Clique em Abrir no Colab. É preciso entrar com uma conta Google (a conta escolar serve).
  2. No menu Arquivo, escolha Salvar uma cópia no Drive. Assim cada pessoa trabalha na sua cópia.
  3. Rode as células de cima para baixo com o botão de play ou com Shift + Enter. A primeira célula, Configuração, sempre vem antes.
  4. Troque os campos ao lado das células (nome do verbete, número de meses, semente) e rode de novo para ver o que muda.
  5. Cada notebook tem um desafio "Sua vez" com uma solução escondida, e perguntas para discutir com a turma.

Sem computador para todos? Projete o notebook e conduza a aula com a turma decidindo os valores. Para uma versão sem código, use o painel de interesse por IA, o plano de aula A Wikipédia como base de dados e o jogo Qual verbete tem mais visitas.

Fontes
