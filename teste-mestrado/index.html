Configuração para quem ajuda (opcional)

Objetos comuns são reconhecidos no próprio celular. Para chave, extintor, saída e outros, o site manda uma foto para o Claude. Cole uma chave da API da Anthropic; ela fica só neste navegador.

Percursos, lugares e pessoas cadastradas ficam só neste celular. Dá para salvar uma cópia em texto ou levar para outro celular.

Se os passos não estão sendo contados ao gravar um percurso, aumente. Se conta passos parado, diminua.

Cadastrar pessoa por foto

Escolha de 1 a 5 fotos com o rosto de frente e bem iluminado. Fica guardado só um código numérico do rosto, neste celular; a foto não é guardada nem enviada.
