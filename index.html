★ moedas-brasileiras

Objetivo: Prever o tipo/denominação de uma moeda brasileira diretamente a partir de uma fotografia.

Tecnologias: Python, Machine Learning (ML), Visão Computacional, Google Cloud (Storage e Serviços de ML).

- Aquisição de Dados: Capturamos mais de 100 fotos de moedas da segunda família do Real brasileiro para criar um conjunto de dados próprio.

- Infraestrutura na Nuvem: Armazenamos e gerenciamos o conjunto de dados em um bucket do Google Cloud Storage.

- Modelagem & Classificação: Processamos as imagens das moedas e testamos vários algoritmos de classificação para separá-las com precisão em grupos correspondentes ao valor de cada moeda.
