A CPU faz o que as instruções mandam

A operação de uma CPU é determinada pelas instruções que ela executa. Cada linha de assembly corresponde a uma instrução de máquina.

Elementos de uma instrução

Código de operação
qual operação fazer (soma, leitura da memória, desvio).
Operandos fonte
de onde vêm os dados de entrada.
Operando de destino
onde guardar o resultado.
Próxima instrução
onde buscar a seguinte. No MIPS fica implícita: PC + 4, exceto nos desvios.

Cada instrução precisa conter toda a informação para a CPU executá-la.

RISC x CISC

RISC
Poucas instruções simples e de tamanho fixo (32 bits no MIPS). Memória só por lw e sw. Pensada para o pipeline e para a otimização pelo compilador. Ex.: MIPS, ARM, RISC-V.
CISC
Muitas instruções, de tamanho variável (1 a 15 bytes no x86). Uma instrução pode fazer várias operações e acessar a memória direto. Ex.: x86.

Somar um valor da memória: x86 faz add eax, [ebx]; MIPS faz lw e depois add.

O que é o MIPS?

32
registradores
de 32 bits cada ($t0, $s0, $zero...)
32 bits
por instrução
sempre o mesmo tamanho
3
formatos
R (registradores), I (imediato), J (salto)

Arquitetura de conjunto de instruções (ISA) do tipo RISC, criada em Stanford nos anos 1980. Base do livro de Patterson e Hennessy e parente direto do RISC-V.

Somando 5 + 7

li $t0, 5 # $t0 = 5 li $t1, 7 # $t1 = 7 add $t2, $t0, $t1 # $t2 = 12

li é uma pseudoinstrução: o montador troca por addiu $t0, $zero, 5.

add é formato R: três registradores.

Do assembly ao binário

add $t2, $t0, $t1 = 000000 01000 01001 01010 00000 100000 = 0x01095020. O op 0 diz “formato R”; o funct diz qual operação.

Resumo da aula

  • Uma instrução de máquina é uma sequência de bits que carrega a operação e os operandos.
  • Assembly é a forma legível dessas instruções; cada arquitetura, RISC ou CISC, tem o seu.
  • MIPS é uma arquitetura de conjunto de instruções RISC: 32 bits, formatos R, I e J.
